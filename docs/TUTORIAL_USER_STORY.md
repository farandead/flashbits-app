# Tutorial User Story - flashbits App Guide

## Overview
A comprehensive tutorial that appears once after onboarding to teach users about:
1. Settings & Customization
2. Streak System
3. XP & Ranking System

## Implementation Notes

### Tutorial Flow
1. Show tutorial after onboarding completion (first time only)
2. 3 main sections: Settings → Streaks → XP/Ranks
3. Each section has 3-4 scenes with images and descriptions
4. Swipe or tap to navigate between scenes
5. "Skip" option available, but encourage completion
6. "Got it!" button to complete tutorial
7. Store completion flag in user profile to prevent showing again

### Visual Style Guidelines
- **Color Scheme:** Dark background (#0A0A0B), cyber-green accent (#00FF94)
- **Typography:** Clean, modern, readable
- **Icons:** Consistent icon set (Ionicons style)
- **Animations:** Smooth transitions, subtle celebrations
- **Layout:** Mobile-first, centered content, clear hierarchy

### Image Specifications
- **Format:** PNG with transparent background (for overlays) or full screens
- **Dimensions:** 1080x1920px (9:16 aspect ratio for mobile)
- **Style:** Modern mobile UI mockups, clean and professional
- **Elements:** Show actual app UI elements, not abstract illustrations

### Text Tone
- Friendly and encouraging
- Clear and concise
- Action-oriented
- Motivational without being pushy
- Professional but approachable
